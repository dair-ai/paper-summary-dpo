**Curator's take**

Modern coding agents can write code, launch experiments and analyze results with little human input, but fully autonomous agents have a limited ideation radius and tend to hill-climb. Robert Tjarko Lange et al. introduce The Agentic Scientist, an end-to-end pipeline that lets human researchers run computational research alongside coding agents. The system drafts tasks, generates ideas, plans, runs sandboxed experiments, aggregates results, builds baselines and ablations, analyzes post-hoc and writes reports. A meta-controller runs parallel agents and enforces rubric verification at each stage.

**Key points**

- **Co-scientist paper.** A development version of the system helped write a paper on backpropagation-free error diffusion learning algorithms that was accepted as an ALIFE 2026 talk after limited human edits.
- **Cross-domain results.** The system was applied to hypernetwork-based LLM adaptation, a meta-trained evolution strategy that matches or exceeds CMA-ES on 5 of 7 unseen Brax control tasks, and RL-based LLM fine-tuning.
- **autoillustrate.** An agentic figure generation pipeline that outperforms PaperBanana on PaperBananaBench, scoring 37.5 against 25.0.
- **Why it matters.** The authors argue that reliable scientific autonomy depends on both base model capabilities and the cross-agent orchestration layer.
