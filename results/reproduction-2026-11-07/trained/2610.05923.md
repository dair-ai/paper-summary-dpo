**Curator's take**

Long-horizon agentic work, like medical research, needs precise, verifiable environments that score each step, not just the final outcome. Most current environments score only the end result, so agents cannot learn from intermediate failures. Junqi Liu et al. present VERA, which builds such environments from existing benchmark trajectories. A coding agent writes binary rubrics, an agent judge verifies each sandbox, and only those that pass enter the training bank. The agent and its harness then co-evolve on these environments, with verifiers gating each update.

**Key points**

- **Environment construction.** Trajectories become restartable sandboxes with stage-wise rubrics. A failed executable check overrides any judge score.
- **Co-evolution loop.** The model trains with rubric rewards, or the harness edits skills, and verifiers gate each change.
- **Results.** At 9B, the co-evolved agent beats the strongest baseline by 10.3 points on AutoCoWorkBench and 13.0 on AutoMedBench. At 27B it scores 71.6 on AutoCoWorkBench and 80.7 on AutoMedBench.
- **Transfer.** The 27B agent transfers to unseen workflows on Automation-Bench and AgentClinic.
- **Open corpus.** The authors release 9,000+ verifiable long-horizon environments.
- **Why it matters.** Precise, verifiable environments let agents learn from every step, not just the final outcome.
