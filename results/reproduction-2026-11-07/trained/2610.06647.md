**Curator's take**

Reinforcement learning pushes LLMs forward, but its memory demands keep many researchers from training models. Gradients and optimizer states can take several times more memory than the weights themselves. Shaokun Zhang et al. propose LoGRA, which keeps learning signals in low-rank gradient sketches. The sketches are used for both model updates and policy synchronization, and a predicted-KL step controller keeps updates from disrupting learning.

**Key points**

- **Sketch updates.** LoGRA accumulates sketches during backpropagation, so it never builds full gradients for the selected weight matrices.
- **Memory savings.** Across reasoning tasks, LoGRA cuts average training memory by 21.8% at 1.5B and 45.7% at 7B, without hurting performance.
- **Large models.** It trains a 27B model for over 1,100 steps on a single eight-GPU node, where dense Adam runs out of memory.
- **Why it matters.** Lower memory use makes RL post-training practical on hardware that can run the model but not train it.
