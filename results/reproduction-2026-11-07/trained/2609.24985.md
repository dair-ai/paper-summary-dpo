**Curator's take**

Multi-turn tool use can fail because of a single model call, but a trajectory-level reward does not say which call would benefit from training. Reward variation mixes differences between actions with randomness in later interactions. Zixiang Chen et al. introduce Critical-State RL, a training-free diagnostic that separates action-dependent reward variation from continuation noise. It then trains the selected calls with contextual-bandit training.

**Key points**

- **How it works.** The diagnostic samples alternative actions at a fixed context, then holds each action fixed while resampling its continuation. The selected calls are those whose reward variation comes from the action, not downstream noise.
- **Four-cell Gemma study.** On the Berkeley Function Calling Leaderboard v4, the diagnostic selects the response after tool availability for missing-function tasks and the response before missing arguments arrive for missing-argument tasks.
- **Results.** Training the selected turns improves performance. For missing-function tasks, the miss_func arm records 0.14 to 0.283 ± 0.015 across four seeds. For missing-argument tasks, the miss_param arm records 0.435 to 0.473 ± 0.010.
- **Other settings.** The same recipe applies to logged repeat-call avoidance, Nemotron missing-function interactions and memory management.
- **Why it matters.** Reward variation alone does not reveal which call would benefit from training. The diagnostic identifies trainable states before training.
