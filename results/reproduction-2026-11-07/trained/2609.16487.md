**Curator's take**

Data-science agents often answer questions about live, continuously updated data, so a static reference answer becomes stale as the data changes. Aniruddha Tamhane et al. propose ground-truth-as-code, which encodes each expected answer as an executable Python function that recomputes the answer from the live data at evaluation time. They pair this with a factoid-level, format-agnostic judge that scores precision, recall and accuracy over atomic claims, regardless of whether the agent replies in prose, a list or a table.

**Key points**

- **Ground-truth-as-code.** Each expected answer is a runnable function, so the reference stays consistent with the data state the agent sees.
- **Format-agnostic scoring.** The judge decomposes both the agent's response and the computed ground truth into factoids, scoring them without seeing the raw format.
- **Human-LLM agreement study.** On an in-production ML skill, the method improves the Matthews Correlation Coefficient by 29% (0.427 vs. 0.331) over a natural-language baseline and cuts token cost per test case by 16%.
- **Self-directed baseline.** A baseline without explicit ground truth is anti-correlated with human judgment (MCC = -0.379).
- **Why it matters.** Agents that integrate multi-source data over non-stationary data are common in industry, and ground-truth-as-code offers a practical way to evaluate them.
