**Curator's take**

Aniruddha Tamhane et al. address the challenge of evaluating data‑science agents that answer queries over live, continuously updated data. They propose ground‑truth‑as‑code, where each expected answer is an executable function recomputed from the current data, and a format‑agnostic factoid scorer that measures precision, recall, and accuracy on atomic claims.

**Key points**

- **Ground‑truth‑as‑code.** Each expected answer is encoded as a runnable Python function that recomputes the answer from the live system at evaluation time, keeping the reference consistent with data drift.
- **Factoid‑level scoring.** An LLM judge decomposes both the agent’s response and the computed ground truth into atomic claims and scores precision, recall, and accuracy, independent of response format.
- **Human–LLM agreement.** Compared to a natural‑language ground‑truth baseline, the method improves the Matthews Correlation Coefficient by 29% (0.427 vs. 0.331) and reduces token consumption per test case by 16%.
- **Self‑directed baseline.** A baseline lacking explicit ground truth is anti‑correlated with human judgment (MCC = −0.379).
- **Why it matters.** The approach provides a practical methodology for evaluating agents that perform multi‑source data integration and computation over non‑stationary data, a common scenario in industry.
