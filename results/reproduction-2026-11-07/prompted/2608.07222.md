Curator's take  
Neural scaling laws assume model size and training data affect loss independently, which causes systematic bias at the grid corners. Mathurin Videau et al. propose the Skaling law, adding a single coupling exponent between model size and data to correct this bias and enable accurate predictions from sparse experiments.

Key points  

- **Coupling exponent.** Skaling introduces one interaction exponent between model size and training tokens, restoring the cross‑derivative that additive laws miss.  
- **MAPE reduction.** Across multiple cross‑validation strategies, Skaling cuts extrapolation MAPE by 1.5 to 3 times compared to the Chinchilla law.  
- **Sparse profiling.** Using an L‑shaped grid that sweeps data for small models and model size for a fixed data amount, Skaling matches full‑grid accuracy while saving about 10× compute.  
- **Why it matters.** Reliable performance prediction from small‑scale runs lets researchers allocate compute budgets more efficiently in next‑generation model training.
