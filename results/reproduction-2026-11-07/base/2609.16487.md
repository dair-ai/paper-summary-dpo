**Curator's take**

Data‑science agents that run on live, continuously updated databases need a reference answer that can be recomputed at evaluation time. Aniruddha Tamhane et al. propose “ground‑truth‑as‑code”, where each expected answer is a runnable Python function, and a factoid‑level, format‑agnostic judge that scores precision, recall and accuracy over atomic claims. Their validation on an in‑production ML skill shows a 29% MCC lift over a natural‑language baseline and a 16% token‑cost reduction.

**Key points**

- **Ground‑truth‑as‑code.** Each expected answer is expressed as a runnable Python function that recomputes the answer from live data at evaluation time, keeping the reference invariant to data drift.
- **Format‑agnostic factoid scoring.** An LLM judge decomposes both the agent’s response and the computed ground truth into atomic claims and scores precision, recall and accuracy, independent of prose, tables or HTML.
- **Human–LLM agreement study.** On a synthetic database mimicking production schemas, the method achieves an MCC of 0.427 versus 0.331 for a natural‑language baseline, a 29% improvement, and reduces token consumption per test case by 16%.
- **Self‑directed baseline.** A baseline lacking explicit ground truth is anti‑correlated with human judgment (MCC = –0.379).
