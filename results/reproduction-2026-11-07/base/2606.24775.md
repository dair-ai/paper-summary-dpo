**Curator's take**  
The paper asks whether we are ready for an agent‑native memory system. Wei Zhou and colleagues from Shanghai Jiao Tong and Tsinghua University systematically evaluate 12 memory architectures from a data‑management perspective, decomposing them into representation, extraction, retrieval, and maintenance modules and measuring effectiveness, fidelity, robustness, stability, and cost.

**Key points**

- **Scope & methodology** – The study evaluates 12 representative memory systems and two baselines across five benchmark workloads covering 11 datasets, using a unified testbed with time‑overhead traces.  
- **No single winner** – No architecture dominates all scenarios; composite hybrid systems excel in conversational QA, while graph‑based methods perform best on single‑hop factual recall but falter on temporal reasoning.  
- **Retrieval accuracy drops with time** – Explicit query planning and balanced hybrid search improve relevance, yet retrieval precision degrades significantly as the temporal distance between evidence and query increases, exposing limits of similarity‑based retrieval.  
- **Dynamic update robustness** – Graph‑based methods handle knowledge updates most reliably; append‑only stores and fact‑extraction plugins struggle with targeted overwrites, leading to stale facts and “hallucinations of the past”.  
- **Long‑horizon stability** – Append‑only stores suffer catastrophic degradation as evidence ages; raw long‑context retrieval still outperforms most memory‑backed approaches for time‑dependent queries, indicating that semantic consolidation can destroy chronological cues.  
- **Operational costs** – Highly structured systems incur orders‑of‑magnitude higher index construction time and query latency than lightweight stores, yet do not consistently deliver proportional accuracy gains.  
- **Why it matters** – The paper highlights that memory design choices directly affect agent reliability, latency, and factual correctness, underscoring the need for principled, data‑management‑oriented evaluation before deploying agent‑native memory in production.
