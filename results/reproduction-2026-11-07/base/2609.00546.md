**Curator's take**

Zhenyu Zhao and Roy Zhao propose Runtime‑Independent Persistent Agents (RIPA), a runtime‑independent architecture that separates an agent’s continuity‑bearing substrate \((I_t,M_t,B_t)\) from replaceable execution and interaction bindings. They implement this in Enoch and demonstrate that identity, memory and body lineage survive model, harness, host and chat‑surface substitutions.

**Key points**

- **Agent boundary.** RIPA defines the persistent substrate \((I_t,M_t,B_t)\) as the agent’s identity, memory and executable body, while reasoner, harness, host and interaction surfaces are replaceable bindings.
- **Continuity invariants.** Six invariants govern state preservation, capability changes and continuation authority, enforced by a quiesce–checkpoint–validate–bind–rehydrate–resume protocol.
- **Operational evidence.** An established instance retains identity, nonempty memory, body revision and historical task IDs across host, joint Codexto‑Claude model/harness, and chat‑surface substitutions.
- **Cross‑host task.** A separate cross‑host task resumes from a verified artifact checkpoint.
- **Supervised study.** A Codex–Muse–Codex study completes five ordinary round trips and five matched same‑runtime controls on their first attempts after a separate qualification run.
- **Interruption recovery.** A planned worker interruption recovers through the native task API with the checkpoint preserved, a stale reply rejected and one task completion recorded.
- **Limitations.** The results support mechanical continuity for the tested deployments and bounded workflows, but do not establish behavioral equivalence, arbitrary‑task portability, general exactly‑once external effects or unattended reliability.
