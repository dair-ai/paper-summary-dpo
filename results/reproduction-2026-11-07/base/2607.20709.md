**Curator's take**

NVIDIA introduces NVIDIA Object‑Oriented Agents (NOOA), a model‑agnostic Python framework that treats an agent as a single Python class. The authors argue that by mapping agent actions to methods, state to fields, and prompts to docstrings, developers can test, trace, and refactor agents with the same tools they use for ordinary software.

**Key points**

- **Design principles.** NOOA adopts existing Python abstractions: classes for agents, methods for capabilities, type annotations for contracts, asyncio for async work, and normal Python code for tools and orchestration. Agent‑specific features such as context, events, state rendering, long‑term memory, and validated LLM loops are exposed through simple Pythonic APIs.
- **Six model‑facing ideas.** NOOA is, to the authors' knowledge, the first to combine typed input/output, pass‑by‑reference over live objects, code as action, programmable loop engineering, explicit object state, and model‑callable harness APIs for context and events on a single surface.
- **Comparison to other frameworks.** The authors surveyed fourteen agent frameworks and harnesses, finding that many already converge on several of these ideas, often as experimental or partial features. They present a comparison to encourage further adoption.
- **Why it matters.** By unifying agent source code, prompts, contracts, and state into a single Python class, NOOA eliminates the learning curve for developers and ensures agents are immediately ready for testing, tracing, and versioning.
