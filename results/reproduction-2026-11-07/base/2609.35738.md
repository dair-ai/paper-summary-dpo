**Curator's take**

Harness learning trains a proposer model to revise a frozen solver’s harness using execution feedback. The authors show that this meta‑learning approach transfers to unseen reasoning and multi‑hop QA tasks, and that proposers can keep improving harnesses over successive test‑time adaptation rounds.

**Key points**

- **Problem & setup.** A harness is the executable program that organizes model calls and tool use. Adapting it can improve performance without changing model parameters. Harness learning trains a proposer to edit harness code based on execution reports.
- **Training.** The proposer is trained with reinforcement learning, using the performance of the revised harness as reward. It can also be initialized with supervised fine‑tuning.
- **Results.** On Reasoning Gym, a trained 4B proposer outperforms the 35B teacher in single‑step revision. In multi‑hop QA, a proposer trained on HotpotQA transfers to MuSiQue and 2WikiMultihopQA, and can keep improving harnesses over successive rounds.
- **Generalization.** Proposers trained only on seed‑harness inputs continue improving revised harnesses, suggesting generalization across adaptation contexts and tasks.
