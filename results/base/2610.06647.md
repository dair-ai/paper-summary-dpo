**Curator's take**  
LoGRA tackles the memory bottleneck of RL post‑training for large language models by keeping only low‑rank sketches of gradients. NVIDIA researchers propose that these sketches, combined with a predicted‑KL step controller, let a 27B model train stably on a single eight‑GPU node while cutting average memory use by up to 45.7 % on reasoning tasks.

**Key points**

- **Memory savings** – LoGRA reduces average training memory by 21.8 % for a 1.5B model and 45.7 % for a 7B model, without hurting task performance.  
- **Large‑scale feasibility** – With LoGRA, a 27B‑parameter model can train for over 1,100 steps on a single eight‑GPU node; the dense Adam baseline runs out of memory at the same hardware allocation.  
- **Compression mechanism** – The method accumulates low‑rank gradient sketches during backpropagation, avoiding full‑gradient storage and enabling compact updates that are also reused for policy synchronization.  
- **Stability control** – Predicted‑KL step control estimates the policy change before each update and scales the update to stay within a KL budget, preventing disruptive large updates.  

*Why it matters* – By cutting RL training memory by nearly half, LoGRA lowers the hardware barrier for researchers to apply RL to very large language models, making previously infeasible training runs practical.
