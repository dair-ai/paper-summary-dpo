**Curator's take**  
GitSwarm tackles the problem of *long‑horizon problem solving and scientific research* by letting many identical agents persistently store and build on each other’s intermediate work. The authors, a team from Meta, Meta‑Superintelligence Labs, Mila, and others, propose an asynchronous system that uses a branchable Git repository as structured, persistent memory, with atomic commits and explicit semantic dependencies.

**Key points**

- **Compounding inference** – The paper defines a new paradigm in which inference‑time computation is organized so that intermediate artifacts persist and can be inspected, extended, or combined by later agents.  
- **GitSwarm architecture** – Homogeneous workers operate asynchronously, inspect previous commits, and decide whether to explore, experiment, verify, refine, or synthesize. Each contribution is an atomic commit; semantic dependencies link work across branches, preserving competing approaches while recording how later work builds on earlier branches.  
- **Long‑horizon problem solving** – On IMOProofBench‑Advanced, GitSwarm solves all 30 problems in one run using Codex (GPT‑5.5‑High) workers and slightly under one million output tokens. On ProgramBench, it achieves a 79.39 % mean score, compared with 65.12 % for the strongest reported baseline (Forced Codex) under the same compute budget.  
- **Sustained experimental research** – On Residual Matrix Transformer, two configurations reach held‑out losses of 2.890 and 2.894 versus 3.147 for the reference, using the same 1.3 B‑token training budget. Similar improvements are reported for Looped Transformer and NanoChat.  
- **Accumulation evidence** – Across ProgramBench runs, 94.7 % of contributions are subsequently referenced, and the selected solution’s transitive ancestry covers 81.6–92.6 % of the contribution graph on average, largely through declared cross‑branch dependencies.  
- **Why it matters** – The results demonstrate that inference‑time computation can accumulate across otherwise independent episodes, forming an evolving body of reusable work that subsequent inference can exploit.
