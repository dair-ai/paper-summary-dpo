**Curator's take**  
The paper tackles the problem of evaluating data‑science agents that must answer queries over live, continuously updated data. An Adobe team proposes “ground‑truth‑as‑code”, where each expected answer is an executable function that recomputes the result from the current data, and a factoid‑level, format‑agnostic judge that scores precision, recall, and accuracy of atomic claims.

**Key points**

- **Problem & Scope** – Data‑science agents perform multi‑source integration and computation over non‑stationary data; static reference answers become stale, making evaluation hard. The authors focus on tasks where the reference can be computed from accessible data APIs.

- **Ground‑truth‑as‑code** – Each expected answer is encoded as a runnable Python function that is executed against the live system at evaluation time. This keeps the reference invariant to data drift and provides a schema contract that fails explicitly when upstream APIs change.

- **Factoid‑level, format‑agnostic scoring** – An LLM‑based judge decomposes both the agent’s response and the computed ground truth into atomic claims (factoids). Precision, recall, and accuracy are scored over these claims, independent of response format (prose, list, table, HTML, etc.), allowing hallucinations or omissions to be directly attributed.

- **Validation study** – On an internally developed, in‑production ML skill using a synthetic database that reproduces production schemas and temporal structure, the method improves the Matthews Correlation Coefficient (MCC) by 29 % (0.427 vs. 0.331) relative to a natural‑language ground‑truth baseline and reduces token consumption per test case by 16 %. A self‑directed baseline lacking explicit ground truth is anti‑correlated with human judgment (MCC = −0.379).
