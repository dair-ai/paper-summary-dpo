**Curator's take**  
The paper asks whether a general-purpose shell can beat specialized tool interfaces on enterprise agent tasks. Hazel Mak et al. run a controlled ablation on two workplace benchmarks (TheAgentCompany and APEX‑Agents) using Opus‑4.8 and GPT‑5.5, and find that bash alone consistently outperforms typed‑tool interfaces while using fewer tokens. They conclude that bash is preferable when arbitrary execution is allowed, and programmatic tool calling (PTC) is better only when a fixed tool catalog is required.

**Key points**

- **Bash vs. Typed Tools** – Bash alone improves score by 21.8–24.5 pp on TheAgentCompany and 4.8–7.4 pp on APEX‑Agents, while using 19–72 % fewer total tokens.  
- **Adding Tools or Synthesis** – Combining typed tools or persistent tool synthesis with bash produces no detectable pooled score gain.  
- **Programmatic Tool Calling (PTC)** – PTC uses fewer tokens than direct typed calls and has broadly similar task performance, but generally underperforms bash alone in both quality and cost efficiency.  
- **Practical Guidance** – For enterprise practitioners, bash alone is favored when arbitrary execution can be isolated; PTC is recommended when security or compliance policies require a fixed tool catalog.
