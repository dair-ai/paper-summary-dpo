**Curator's take**  
HybridReasoning Agents (HybridAgents) aim to combine the efficiency of latent reasoning with the tool‑access and transparency of text‑based LLM agents. Jiaru Zou et al. from Stanford, Together AI, UIUC, and Meta propose a lightweight HybridLink that lets a model switch between latent and text modes during a single generation, and introduce post‑training methods (HybridSFT and HybridRL) to stabilize and scale this hybrid behavior.

**Key points**

- **HybridLink architecture** – A residual adapter maps last‑layer hidden states back into the input embedding space, enabling the agent to enter latent mode for fast, inspectable inner thinking and return to text mode for tool calls and external monitoring.

- **Multi‑turn hybrid generation** – The agent’s continuous working memory preserves lossless hybrid context (text, latent thoughts, tool observations) across turns, allowing seamless transitions without losing information.

- **Post‑training algorithms** – HybridSFT stabilizes tool‑integrated hybrid generation by teaching the backbone to coordinate with HybridLink; HybridRL trains the agent to learn when to think in latent space versus act through text, using hybrid policy factorization and exact rollout replay.

- **Performance and efficiency** – Across 3 model scales (4B, 8B, 14B) and 11 benchmarks (mathematics, science, medicine, search, agentic reasoning), HybridAgent improves average performance by 10.4% over frontier LLM agents and agentic frameworks. It also reduces token usage by 35.5%–54.7%, speeds inference by 1.8×–2.6×, and cuts computational cost by 2.7×–3.7×.

- **Why it matters** – By unifying latent and text reasoning, HybridAgent offers a scalable, efficient, and transparent agent design that can better leverage specialized tools while keeping internal reasoning inspectable.
