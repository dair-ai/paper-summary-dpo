**Curator's take**  
EvoOntology tackles the agent–data gap in data agents that must operate over heterogeneous sources such as tables, files, and databases. The authors from Renmin University of China propose a self‑evolving ontology layer, implemented as an MCP server, that agents can query and update at runtime. By autonomously building and refining the ontology through attribution‑guided edits and paired evaluation, EvoOntology aims to give agents a semantic foothold on otherwise opaque data.

**Key points**  
- **Problem & Motivation** – Data agents must interact with data that lives outside the agent and is only reachable via generic tools (SQL, file readers). Without prior knowledge of structure or content, agents blindly probe the data, creating a persistent agent–data gap.  
- **Solution Architecture** – EvoOntology is an MCP server comprising a schema layer (object types & reference rules), a content layer (domain knowledge & data mappings), and a tool layer (executable interfaces). Agents actively query and manipulate this ontology instead of passively consuming static metadata.  
- **Builder Agent & Self‑Evolution** – A builder agent first constructs an initial ontology by issuing probe queries and grounding entries in observed data. The ontology then self‑evolves: attribution analysis identifies deficiencies, targeted refinements are proposed, and each refinement is accepted only after passing a paired evaluation on a held‑out validation set.  
- **Empirical Claims** – Experiments on three well‑adopted data‑agent benchmarks with four LLM backbones show that EvoOntology consistently and substantially outperforms strong baselines and existing semantic‑layer approaches, effectively bridging the agent–data gap.  
- **Why it matters** – By providing an interactive, automatically maintained semantic layer, EvoOntology enables data agents to understand and manipulate heterogeneous data more efficiently, addressing scalability and adaptability challenges that limit current raw‑querying and manually curated semantic‑layer methods.
