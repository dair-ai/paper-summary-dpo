**Curator's take**  
The paper tackles the XY problem in human‑AI interaction: users give a plausible but incorrect suggestion (X) while the true goal is Y. Zhengxuan Wu, Yuxuan Li, Oyvind Tafjord, and Been Kim from Google DeepMind propose XYEval, a meta‑evaluation framework that mutates existing benchmarks with such misleading suggestions and measures how much agent performance drops. They find that current agents suffer large XY drops—up to 46.7%—and that simple instruction tweaks only partially help.

**Key points**

- **XYEval framework** – XYEval automatically injects a plausible but incorrect user suggestion into any benchmark instruction, then measures the agent’s retained performance relative to the original score.  
- **Benchmark coverage** – The authors instantiate XYEval on six diverse agentic benchmarks: 𝜏²‑bench, SWE‑bench Verified, Swe‑bench Pro, Terminal‑Bench, Humanity’s Last Exam, and MCP‑Atlas.  
- **Performance drops** – Across all models, relative drops reach up to **46.7%** when faced with XY mutation, indicating widespread susceptibility.  
- **Pedantic users** – On 𝜏²‑bench, agents perform even worse when the user demands detailed explanations before approving a better solution, highlighting communication gaps.  
- **Mitigation limits** – A system instruction baseline that encourages awareness of XY problems offers only partial mitigation; agents still struggle to verify and communicate the true problem.  
- **Why it matters** – The study shows that effective human‑AI collaboration requires agents to detect misleading suggestions and articulate the underlying issue, a capability current models lack.
