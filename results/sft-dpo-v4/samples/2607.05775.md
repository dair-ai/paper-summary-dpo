**Curator's take**

Large language model agents are being tested on tool use, planning, multi-agent coordination and long horizons, and leaderboards show steady gains. But the papers that introduce and stress-test these benchmarks keep finding the same failure patterns, such as agents fabricating tool names, plans that satisfy constraints in isolation but not jointly, performance that collapses before context windows are exhausted and coordination overhead erasing collaboration benefits. Wael Albayaydh et al. synthesize 27 papers covering 19 benchmarks into a single taxonomy of agent limitations, and they also point out where agents have genuinely improved.

**Key points**

- **Six failure clusters.** Tool invocation errors, planning and constraint-satisfaction failures, long-horizon degradation from context accumulation, multi-agent coordination failures, safety and security failures under adversarial or underspecified conditions and measurement validity problems.
- **Progress is uneven.** Single-turn tool selection, short-horizon web navigation and narrowly scoped coding tasks all show substantial, credible progress.
- **Failure compounds non-linearly.** Across clusters, failure compounds non-linearly with task length.
- **Sub-skill competence does not compose.** Sub-skill competence does not reliably compose into end-to-end success.
- **Scaffolding is not a silver bullet.** Additional scaffolding does not uniformly improve reliability.
- **Why it matters.** Progress on agent benchmarks hides recurring failure modes that keep agents from reliable deployment.
