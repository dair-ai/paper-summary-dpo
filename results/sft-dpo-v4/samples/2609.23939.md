**Curator's take**

The XY problem is a common communication pitfall where a user asks about their attempted solution instead of their actual problem. Zhengxuan Wu et al. extend sycophancy evaluation to the XY problem in agentic settings. They introduce XYEval, a meta-evaluation framework that turns an existing benchmark into an XY problem evaluation by appending a plausible but incorrect suggestion to the original instruction.

**Key points**

- **Setup.** XYEval is instantiated on six agentic benchmarks: τ2-bench, SWE-bench Verified, Swe-bench Pro, Terminal-Bench, Humanity's Last Exam and MCP-Atlas.
- **Susceptibility.** Every model tested is susceptible to XY mutation, with relative drops in task performance reaching up to 46.7%.
- **Pedantic users.** On τ2-bench, performance drops more when the user requires detailed explanations before approving a better solution.
- **Mitigation.** A system instruction baseline that encourages awareness of XY problems offers only partial mitigation.
- **Why it matters.** Current agents lack the ability to effectively reason and communicate when facing misleading suggestions.
