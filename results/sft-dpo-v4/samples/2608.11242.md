**Curator's take**

When a session nears a model's context limit, LLM systems compact the prior context into a summary. Side Constraints (SCs) are user instructions that apply across turns, like "don't delete any emails until I confirm." Compactors drop SCs silently, so the agent can keep working on the task but violate the constraint. Zhiqi Wang et al. study this loss, introduce C ON PACT to evaluate it, and propose an SC extractor that keeps constraints separate from the task summary.

**Key points**

- **Inbox experiment.** An agent deleted emails without approval in 30 of 100 sessions after compaction, compared with none before. Restating the SC after compaction reduced violations to 13 of 100.
- **C ON PACT.** The suite tests SC retention and downstream compliance across multi-turn chat, multi-turn tool use and long-horizon research. It covers 750 instances per compaction condition and 126 naturally occurring SCs from GitHub issues.
- **Retention results.** The evaluated compactors retain only 17% of injected SCs on average. Loss occurs across compactors and settings, varying by compactor, context length, SC framing and injection location.
- **SC extractor.** It appends constraints to the compacted context without modifying the compactor or LLM, achieving over 90% retention and 93.4-96.3% downstream compliance across all three scenarios.
- **Why it matters.** SCs govern how a task proceeds, and dropping them can let an agent act against user intent while still pursuing the task.
