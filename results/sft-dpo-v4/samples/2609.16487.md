**Curator's take**

Data-science agents that run over live, continuously updated databases need a reference answer that stays current. Aniruddha Tamhane et al. propose ground-truth-as-code, which encodes each expected answer as an executable Python function that recomputes the answer from the same live data the agent sees. They pair this with a factoid-level, format-agnostic judge that scores precision, recall and accuracy over atomic claims, so presentation quality does not mix with factual correctness.

**Key points**

- **Ground-truth-as-code.** Each expected answer is a runnable function, so the reference stays invariant to data drift and fails explicitly when an upstream API changes.
- **Format-agnostic scoring.** The judge decomposes both the agent's response and the computed ground truth into atomic claims, scoring precision, recall and accuracy over them.
- **Human-LLM agreement study.** On an internally developed ML skill deployed in production, the method improves the Matthews Correlation Coefficient (MCC) by 29% (0.427 vs. 0.331) over a natural-language ground-truth baseline.
- **Lower cost.** The method reduces token consumption per test case by 16%.
- **Self-directed baseline.** A baseline lacking explicit ground truth is anticorrelated with human judgment (MCC = -0.379).
- **Why it matters.** Agents that integrate multi-source data over non-stationary data are routinely deployed in industry, and ground-truth-as-code offers a practical way to evaluate them.
