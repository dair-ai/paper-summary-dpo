**Curator's take**

Enterprise agents move between applications, coordinate with coworkers and perform professional analysis, not just code. Hazel Mak et al. compare five tool interfaces on two enterprise benchmarks, TheAgentCompany and APEX-Agents, using Opus-4.8 and GPT-5.5. They ask whether a general shell can beat specialized tools.

**Key points**

- **Bash alone wins.** Bash alone outperforms typed tools on both benchmarks, improving score by 21.8 to 24.5 points on TheAgentCompany and 4.8 to 7.4 points on APEX-Agents while using 19 to 72% fewer total tokens.
- **No gain from adding tools.** Adding typed tools or persistent tool synthesis to bash produces no detectable pooled score gain.
- **PTC is cheaper but weaker.** Programmatic tool calling uses fewer tokens than direct typed calls with broadly similar task performance, but generally underperforms bash alone in both quality and cost efficiency.
- **Why it matters.** For enterprise practitioners, bash alone is best when arbitrary execution can be isolated, and programmatic tool calling when a fixed tool catalog is required by security or compliance policies.
