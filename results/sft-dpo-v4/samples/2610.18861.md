**Curator's take**

Modern LLM agents reason and act through text, while latent reasoning is efficient but opaque and lacks tool access. Jiaru Zou et al. propose HybridReasoning Agents (HybridAgents), which move between latent reasoning and text-based interaction within a single generation. A lightweight HybridLink bridges latent thoughts back into the input embedding space, and the agent's working memory preserves the whole hybrid context across turns.

**Key points**

- **HybridLink.** A residual adapter maps last-layer hidden states into the input embedding space, enabling recurrent latent thinking and return to text mode for tool calls.
- **HybridSFT.** This post-training step stabilizes tool-integrated hybrid generation by teaching the backbone to coordinate with HybridLink.
- **HybridRL.** Policy optimization over hybrid trajectories learns when to think in latent space and when to act through text.
- **Results.** Across 3 model scales and 11 benchmarks in mathematics, science, medicine, search and agentic reasoning, HybridAgent improves performance by 10.4% on average. It reduces token usage by 35.5% to 54.7%, speeds inference by 1.8x to 2.6x and cuts cost by 2.7x to 3.7x.
- **Why it matters.** Latent thoughts become inspectable pseudo-text, so the agent keeps tool access while making internal reasoning transparent.
