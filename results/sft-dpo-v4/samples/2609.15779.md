**Curator's take**

Data agents must understand heterogeneous data that lives outside the agent, but they can only access it through generic tools. Existing methods either let agents probe raw data, which scales poorly, or inject manually built semantic layers, which are costly to maintain. Meiduo Chong et al. propose EvoOntology, a self-evolving ontology layer that agents can query through tools. It adapts to both the data and the agent's behavior.

**Key points**

- **Three layers.** The ontology has a schema layer, a content layer and a tool layer, all wrapped in an MCP server.
- **Builder agent.** An autonomous builder agent constructs the initial ontology by probing the data sources.
- **Self-evolution loop.** Attribution analysis finds deficiencies, the ontology is refined and each change is accepted only after a paired evaluation on a held-out validation set.
- **Results.** On three data-agent benchmarks with four LLM backbones, EvoOntology consistently outperforms strong baselines and existing semantic-layer approaches.
- **Why it matters.** A self-evolving ontology bridges the agent-data gap and lets agents interact with heterogeneous data at the semantic level.
