**Curator's take**  
MSCE tackles the problem of turning long‑horizon LLM agent experience into reusable, verifiable skills. First author et al. propose a training‑free Memory–Skill Co‑Evolution framework that organizes experience into grounded traces, procedural policies, and declarative environmental cognition, then promotes only evidence‑backed, positive‑gain policies into callable skills while propagating sparse terminal feedback through reflection‑weighted value back‑filling.

**Key points**  
- **Memory hierarchy.** MSCE separates experience into L1 trace memory (grounded step‑level evidence), L2 policy memory (recurring procedural patterns), and L3 environmental cognition memory (declarative knowledge about structure and constraints).  
- **Skill promotion criteria.** A policy is promoted to a skill only if it retains supporting evidence, shows positive estimated gain, and remains consistent with its trigger, procedure, and applicability boundary.  
- **Reflection‑weighted value back‑filling.** Sparse terminal feedback is propagated through dense local self‑reflections to produce evidence‑calibrated trace values that guide retrieval, policy induction, environmental abstraction, skill promotion, and revision.  
- **Why it matters.** By converting noisy interaction histories into governable abstractions, MSCE enables agents to reuse experience efficiently, reduce token consumption, and maintain coherent, personalized behavior across long‑horizon, multi‑step tasks.
