Curator's take:  
The paper tackles the problem that existing neural scaling laws, particularly the additive Chinchilla law, systematically mis‑predict loss at the edges of the training grid because they ignore the interaction between model size and training data. Mathurin Videau, Badr Youbi‑Idrissi, David Lopez‑Paz, and Kartik Ahuja propose the Skaling law, a minimal extension that couples size and data through a single interaction exponent, and show it yields more accurate predictions and enables a cheaper “L‑shape” profiling strategy.

Key points  
**Skaling law.** The Skaling form introduces one coupling exponent between model size and data volume, correcting the boundary biases of additive laws.  
**MAPE improvement.** Skaling reduces the Mean Absolute Percentage Error by 1.5–3× relative to Chinchilla across multiple cross‑validation strategies.  
**Sparse profiling.** Using an “L‑shape” grid that sweeps data volume for small models (D‑band) and model size on a small, fixed amount of data (N‑band), Skaling achieves predictive accuracy matching a full‑grid fit while requiring up to 10× less compute.  
**Why it matters.** By providing a more reliable and resource‑efficient framework for performance prediction, Skaling helps researchers allocate compute budgets more effectively in next‑generation model training.
