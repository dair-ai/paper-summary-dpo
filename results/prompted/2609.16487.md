**Curator's take**  
The paper tackles the problem of evaluating data‑science agents that must answer queries over live, continuously updated data. Aniruddha Tamhane et al. propose a framework that encodes expected answers as executable reference functions—ground‑truth‑as‑code—and scores agent outputs at the factoid level in a format‑agnostic way, thereby keeping the reference consistent with the current data state.

**Key points**

- **Ground‑truth‑as‑code.** Each expected answer is expressed as a runnable Python function that recomputes the answer from the live data at evaluation time, ensuring the reference remains invariant to data drift and fails explicitly when upstream APIs change.

- **Factoid‑level, format‑agnostic scoring.** An LLM‑based judge decomposes both the agent’s response and the computed ground truth into atomic claims and scores precision, recall, and accuracy over them, independent of prose, tables, or other formats.

- **Human–LLM agreement study.** On an internally developed, in‑production ML skill with a synthetic database mirroring production schemas, the method improves the Matthews Correlation Coefficient by 29 % (0.427 vs. 0.331) over a natural‑language ground‑truth baseline and reduces token consumption per test case by 16 %.

- **Self‑directed baseline.** A baseline lacking explicit ground truth is anti‑correlated with human judgment (MCC = −0.379), highlighting the need for a robust reference.

- **Why it matters.** The framework provides a practical methodology for evaluating agents that perform multi‑source data integration and computation over non‑stationary data, a common scenario in industry production data‑science workflows.
