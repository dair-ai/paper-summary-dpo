Curator's take:  
Harness learning tackles the problem of adapting a language‑model agent’s harness—its executable program that orchestrates model calls and tool use—without changing model parameters. First author Zhang et al. train a proposer model to revise harnesses from execution feedback, framing the process as meta‑learning over programs. At test time the frozen proposer refines harnesses for new tasks using only execution reports.

Key points  
**Proposer training.** The proposer is trained with reinforcement learning, receiving as reward the task performance of the revised harness; it can also be initialized with supervised fine‑tuning.  
**Single‑step advantage.** On Reasoning Gym, a 4B proposer trained with harness learning outperforms a 35B teacher in single‑step revision on task families excluded from both supervised and reinforcement learning.  
**Cross‑benchmark transfer.** A proposer trained on HotpotQA transfers to MuSiQue and 2WikiMultihopQA, improving harnesses on unseen question‑answering benchmarks.  
**Iterative improvement.** Proposers trained on individual revisions can continue refining harnesses over multiple test‑time adaptation rounds, and even a proposer trained only on seed‑harness inputs keeps improving revised harnesses.  
**Why it matters.** Harness learning offers a path toward continually learning agents that convert accumulated execution experience into generalizable harness improvements without updating model parameters.
